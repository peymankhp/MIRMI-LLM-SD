⚙️ CONFIGURE OPEN WEBUI (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Open: https://mirmi-llm.mirmi.tum.de
  2. Admin Panel → Settings → Images → Image Generation
  3. Copy these values:

     ┌────────────────────────────────────────────────────────────────────┐
     │ Image Generation Engine:     AUTOMATIC1111                         │
     │                                                                    │
     │ AUTOMATIC1111 Base URL:      http://automatic1111:7860            │
     │                                                                    │
     │ Api Auth String:             (leave empty)                        │
     │                                                                    │
     │ Image Size:                  768x768                              │
     │                                                                    │
     │ Steps:                       30                                   │
     │                                                                    │
     │ Additional Parameters:                                            │
     │ {                                                                 │
     │   "cfg_scale": 8,                                                 │
     │   "sampler_name": "DPM++ 2M Karras",                              │
     │   "negative_prompt": "blurry, low quality, distorted"             │
     │ }                                                                 │
     └────────────────────────────────────────────────────────────────────┘

  4. Click Save

  Problem: "Connection error"
  
  Solution:
    docker restart automatic1111
    # Wait 30 seconds and try again

  Problem: Images are slow
  
  Solution:
    • Reduce Image Size to 512x512
    • Reduce Steps to 20

  Problem: Images are low quality
  
  Solution:
    • Increase Steps to 40-50
    • Add quality keywords: "highly detailed, 8k, photorealistic"
