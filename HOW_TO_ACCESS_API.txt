   python3 example_api_usage.py
   
   Or use this simple code:
   
   import requests
   
   response = requests.post(
       "http://localhost:11434/api/generate",

           "model": "mistral:latest",
           "prompt": "Explain AI in simple terms",
           "stream": False
       }
   )
   print(response.json()['response'])

4. USE WITH VS CODE (Continue Extension)
   
   Install Continue extension, then configure:
   
   {
     "models": [{
       "title": "Mistral Local",
       "provider": "ollama",
       "model": "mistral:latest",
       "apiBase": "http://localhost:11434"
     }]
   }

5. USE WITH OPENAI SDK
   
   pip install openai
   
   from openai import OpenAI
   
   client = OpenAI(
       base_url='http://localhost:11434/v1',
       api_key='ollama'
   )
   
   response = client.chat.completions.create(
       model="mistral:latest",
       messages=[{"role": "user", "content": "Hello!"}]
   )
   
   print(response.choices[0].message.content)

🔧 PARAMETERS YOU CAN CONTROL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

temperature: 0.0-2.0 (default: 0.8)
  - Lower = more focused/deterministic
  - Higher = more creative/random

top_p: 0.0-1.0 (default: 0.9)
  - Nucleus sampling threshold

top_k: integer (default: 40)
  - Number of tokens to consider

num_predict: integer (default: 128)
  - Maximum tokens to generate

stream: true/false
  - true = real-time streaming
  - false = wait for complete response

Example:
curl http://localhost:11434/api/generate -d '{
  "model": "mistral:latest",
  "prompt": "Write a story",
  "stream": false,
  "options": {
    "temperature": 0.7,
    "num_predict": 200
  }
}'
