🔧 PARAMETERS EXPLAINED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Temperature (0.0 - 2.0):
  0.0-0.3  → Very focused, deterministic (good for code, facts)
  0.4-0.7  → Balanced (default: 0.7)
  0.8-1.2  → Creative (good for stories, ideas)
  1.3-2.0  → Very creative, random

Max Tokens:
  Controls maximum response length
  Default: 500 tokens (~375 words)
  1 token ≈ 0.75 words

Top P (0.0 - 1.0):
  Nucleus sampling threshold
  Lower = more focused
  Higher = more diverse
  Default: 0.9

Streaming:
  Yes → See response word-by-word in real-time
  No  → Wait for complete response

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Cannot connect to Ollama API"
Solution:
  docker ps | grep ollama
  curl http://localhost:11434/api/tags

Problem: "No models found"
Solution:
  docker exec ollama ollama list

Problem: Flask won't start
Solution:
  pip3 install flask requests

Problem: Slow responses
Solution:
  - Use smaller models (7B instead of 13B)
  - Check GPU: nvidia-smi
  - Reduce max_tokens

Problem: Interface won't open
Solution:
  # Open manually in browser
  firefox web-interface.html
  # or
  google-chrome web-interface.html
