⚠️  IF MODELS DON'T APPEAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  This is a known limitation. VSCode's native chat has limited support
  for custom language models.

  Try these solutions:

  SOLUTION 1: Check Ollama API Compatibility
    Test if Ollama's OpenAI-compatible API works:
    
    curl http://localhost:11434/v1/models
    
    Should return JSON with model list.

  SOLUTION 2: Use LiteLLM Proxy
    Install: pip install litellm
    
    Run: litellm --model ollama/qwen2.5-coder:7b \
                 --api_base http://localhost:11434 \
                 --port 8000
    
    Then update settings endpoint to: http://localhost:8000/v1

  SOLUTION 3: Check VSCode Version
    VSCode must be version 1.85 or newer for custom language models.
    
    Check: Help → About
    Update: Help → Check for Updates

  SOLUTION 4: Check GitHub Copilot Extension
    The native chat requires GitHub Copilot Chat extension.
    
    Press Ctrl+Shift+X → Search "GitHub Copilot Chat"
    Should show "Disable" (meaning it's installed)
