✅ Your MIRMI LLM is running correctly with Docker Compose
✅ You have an NVIDIA RTX 2080 SUPER (8GB VRAM) - perfect for 8B models
✅ You have 167GB free disk space - enough for new models
⚠️  The instructions you received were for manual docker run (not docker-compose)
⚠️  Your Ollama port is NOT exposed (needs fixing)
⚠️  You have a host-level Ollama service that will conflict

🚀 INSTALLATION (RECOMMENDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run this single command:

    ./install-models-safe.sh

The script will:
  1. Create full backups automatically
  2. Fix your docker-compose.yaml to expose Ollama API
  3. Stop the conflicting host Ollama service
  4. Install Llama 3 (8B) and Qwen 2.5 (7B)
  5. Verify everything works
  6. Show you the configuration for external tools

Time: 10-15 minutes (mostly downloading)

🆘 ROLLBACK (IF NEEDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If something goes wrong:

    docker-compose down
    cp backups/<timestamp>/docker-compose.yaml ./
    docker-compose up -d

Backups are in: backups/<timestamp>/

sudo ufw allow from 192.168.1.100 to any port 11434

# Allow from local network
sudo ufw allow from 192.168.1.0/24 to any port 11434

# Check status
sudo ufw status
