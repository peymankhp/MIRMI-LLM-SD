📊 YOUR SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  RAM:              32GB
  Current Swap:     2GB
  GPU:              RTX 2080 SUPER (8GB VRAM)
  Mixtral needs:    ~27GB RAM

🎯 THE PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ❌ Ollama uses 25GB RAM (other models loaded)
  ❌ Only 2.8GB available
  ❌ Not enough for Mixtral (needs 27GB)
  ❌ Have to manually run: sudo sysctl vm.drop_caches=1

✅ THE SOLUTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ONE-TIME SETUP (run once):
  
    sudo ./setup-mixtral-memory.sh
  
  This will:
    • Allow cache clearing without password
    • Increase swap from 2GB to 8GB
    • Setup helper scripts

🚀 USING MIXTRAL (after setup)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  OPTION 1 - Fully Automatic (Recommended):
  
    ./ollama-memory-manager.sh mixtral:8x7b-instruct-v0.1-q4_0
    
    • Clears cache automatically
    • Unloads other models if needed
    • Loads Mixtral when ready
    • One command, done!

  OPTION 2 - Quick Manual:
  
    ./auto-clear-cache.sh
    
    • Clears cache only
    • Then use Mixtral in MIRMI LLM
    • No password needed

  Setup (one-time):
    sudo ./setup-mixtral-memory.sh

  Before using Mixtral:
    ./ollama-memory-manager.sh mixtral:8x7b-instruct-v0.1-q4_0
    OR
    ./auto-clear-cache.sh

  Check memory:
    free -h
    docker stats --no-stream ollama

  Check swap:
    swapon --show

  Check GPU:
    nvidia-smi

  Restart Ollama (free all memory):
    docker restart ollama

💡 TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Before using Mixtral:
    • Close unnecessary applications
    • Run memory manager script
    • Wait 2-5 minutes for model to load

  During use:
    • Don't load other models
    • Keep browser tabs minimal
    • Expect 10-30 second responses

  After use:
    • Switch to smaller model in UI
    • Or restart Ollama to free memory

  For daily use:
    • Use mistral:7b (fast, 4.4GB)
    • Or llama2:7b (fast, 3.8GB)
    • Save Mixtral for best quality needs

⚠️  WHAT TO EXPECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Mixtral Performance:
    Load time:        2-5 minutes
    First response:   15-30 seconds
    Next responses:   10-20 seconds
    Quality:          Excellent (best available)
    Stability:        Good (with 8GB swap)

  Why slower than smaller models?
    • 46.7B parameters (vs 7B)
    • Limited VRAM (8GB GPU)
    • CPU fallback for some layers
    • Worth it for quality!

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "Out of memory" error:
    → Run: ./ollama-memory-manager.sh mixtral:8x7b-instruct-v0.1-q4_0
    → Close other applications
    → Check: free -h

  "Permission denied" when clearing cache:
    → Run: sudo ./setup-sudoers-cache.sh

  Mixtral very slow:
    → Normal! It's a huge model
    → Using swap (slower than RAM)
    → CPU fallback (limited VRAM)
    → Consider llama2:13b for faster responses

  Ollama crashes:
    → Increase swap: sudo ./increase-swap.sh
    → Restart: docker restart ollama
    → Try again with memory manager
