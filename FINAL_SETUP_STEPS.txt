🔧 TROUBLESHOOTING:

  Problem: Continue panel doesn't open
  Solution:
    • Restart VSCode completely
    • Check Continue icon in left sidebar
    • Try Ctrl+Shift+P → "Continue: Open Chat"

  Problem: "Failed to connect to Ollama"
  Solution:
    docker restart ollama
    curl http://localhost:11434/api/tags

  Problem: No response from AI
  Solution:
    • Check model is selected (click model name in chat)
    • Verify Ollama is running: docker ps | grep ollama
    • Check logs: docker logs ollama --tail 20

  Problem: Autocomplete not working
  Solution:
    • Wait 2-3 seconds after typing
    • Try pressing Tab manually
    • Check GPU: nvidia-smi
