🚀 QUICK SETUP (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Install VSCode:
     sudo snap install code --classic

  2. Open VSCode:
     code

  3. Install Continue extension:
     - Press Ctrl+Shift+X
     - Search "Continue"
     - Click Install

  4. Configure Continue:
     - Press Ctrl+Shift+P
     - Type "Continue: Open Config"
     - Paste configuration (see below)

  5. Start coding with AI!
     - Ctrl+L = Open chat
     - Ctrl+I = Inline edit
